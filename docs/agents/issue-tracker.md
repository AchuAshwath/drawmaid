# Issue tracker: GitHub

Issues and pull requests for this repository live in GitHub at
`AchuAshwath/drawmaid`. Use the `gh` CLI for issue and pull-request operations.

PRs are not a request surface for triage. The Wayfinder map and its child
issues are the planning source of truth; use native GitHub issue dependencies
when work is blocked.

Useful commands:

- `gh issue view <number> --comments`
- `gh issue list --state open`
- `gh issue comment <number> --body "..."`
- `gh issue edit <number> --add-label "..."`
- `gh issue close <number> --comment "..."`
