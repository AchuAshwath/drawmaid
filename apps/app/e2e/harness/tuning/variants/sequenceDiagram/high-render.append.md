## Sequence High depth note

Use the sequence vocabulary that best preserves the brief: requests and
replies, explicit alternate paths, repeated stretches, concise participant
notes, and activation spans where handling time matters. Number messages only
when order is the point. Keep participants declared once before messages and
keep every block balanced with `end`; if a richer construct is not supported
by the source, a plain valid exchange is the stronger result.
Before returning, check that every arrow has a non-empty `: message` label and
that notes use concise converter-safe text.
